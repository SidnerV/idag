# **idag**
****

idag er en applikasjon hvor flere enkle hverdagslige redskap skal samles til en plattform.
Målet for idag er for brukerene å få en enklere hverdag der de får en god oversikt over hverdagslige oppgaver, aktiviteter, middagsplaner og handling.

Dette prosjektet er for at jeg skal lære mer om fullstackutvikling. Jeg skal også lære om moderne teknologier. Jeg skal prøve å bruke generativ AI så lite som mulig for å generere kode til prosjektet.


**Stack:**

- React + TypeScript for frontend
- Java + Spring Boot for backend
- PostgreSQL for database
- Authentication: Keycloak

---
Dev urls:
- Keycloak: http://localhost:8081
- Docker: docker start idag-keycloak
- Frontend: http://localhost:5173
- API: http://localhost:8080
